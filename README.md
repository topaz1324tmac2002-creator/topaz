# 주얼리 스튜디오 · RingStudio (1차 프로토타입)

> **아이패드와 PC 웹에서 반지 치수·스톤·각인·자유 조형을 실시간 금속 렌더링으로 디자인하고, 3D 프린팅용 STL 파일까지만 만드는** 웹앱.
> 라이노(Rhino)를 배우기 전에 주얼리의 구조(호수·두께·세팅·중량)를 몸으로 익히는 **관문(on-ramp)** 을 목표로 합니다.

- 타겟: **아이패드(터치) 우선**, PC 웹은 같은 코드로 자동 호환 (반응형)
- 상태: **1차 동작 프로토타입** · 2026-11-14 · 제품 요구사항은 [`docs/prd-v0.3.md`](docs/prd-v0.3.md)
- 스택: React 18 · TypeScript · Vite · three.js · Zustand (서버 없음, 100% 클라이언트)
- 범위: **디자인 → 실시간 금속 렌더링 → 중량/수밀 검증 → STL**. 영상·이미지 내보내기는 하지 않습니다(PRD 4.2).

## 설치형 앱(PWA) — 아이패드·PC

브라우저 탭이 아니라 **앱처럼 전체 화면으로 실행되고, 한 번 열면 오프라인에서도 뜨는** 설치형 앱으로 쓸 수 있습니다.

| 항목 | 파일 |
|---|---|
| 웹 앱 매니페스트(이름·아이콘·표시 모드) | `public/manifest.webmanifest` |
| 앱 아이콘 | `public/icons/icon-192.png`, `icon-512.png`, `apple-touch-icon.png` |
| 오프라인 앱 셸(서비스 워커) | `public/sw.js` (등록은 `src/main.tsx`, 프로덕션 빌드에서만) |
| iOS 설치 메타 태그 | `index.html` (`apple-touch-icon`, `apple-mobile-web-app-*`) |

- **아이패드(Safari)**: 사이트를 연 뒤 공유 → **홈 화면에 추가**. 홈 화면 아이콘 이름은 `Topaz`.
- **PC(Chrome·Edge)**: 주소창 오른쪽 **설치** 아이콘 → 설치. 앱 창으로 열립니다.
- 오프라인 캐시는 `scope` 기준 상대 경로라 `…/topaz/` 같은 하위 경로 배포에서도 동작합니다. 탐색 요청은 네트워크 우선(끊기면 캐시된 `index.html`), 해시된 빌드 자산은 stale-while-revalidate.
- 앱을 새로 빌드해 배포하면 다음 방문 때 자동으로 최신 파일을 받아옵니다(캐시 이름은 `topaz-shell-topaz-v1`).

## 화면 구성 (탭 6개)

```
[상단] 브랜드 · 현재 요약(KS/폭/재질/중량) · 실행취소/다시
[좌측] 밴드 / 스톤 / 조형 / 각인        [중앙] 3D 뷰포트        [우측] 재질 · STL
                                       └ 조형 중 안내(종료 버튼)
[아이패드 세로·모바일] 뷰포트 위 + 하단 시트(밴드·스톤·조형·각인·재질·STL)
```

- 탭은 **밴드 · 스톤 · 조형 · 각인 · 재질 · STL** 여섯 개가 전부입니다. 촬영·공유·갤러리 화면은 두지 않습니다.
- 터치 타겟은 최소 44px. 3D 캔버스는 한 손가락 회전 / 두 손가락 확대, 조형 탭에서 조형을 켜면 손가락이 브러시가 됩니다(다른 탭으로 이동하면 조형은 자동으로 꺼집니다).

## 아직 안 되는 것 (다음 단계)

1. **불리언 합집합 없음** — 프롱·베젤·시트가 밴드와 겹친 채 STL에 들어갑니다. 부품 단위 수밀성은 보장되지만, 슬라이서에서 "합치기(union)"를 한 번 눌러야 합니다. → `manifold-3d`(WASM) 도입 예정
2. **각인은 형상이 아니라 음각 노멀맵** — 미리보기용이며, 주물용 각인 형상(차집합)은 미구현
3. **자유 조형은 파라미터를 바꾸면 초기화** — 변위를 (u,v) 좌표에 저장하는 방식으로 개선 예정
4. `.jwdx` 파일 저장/불러오기, 템플릿 5종, PWA 오프라인, 채널 세팅, 3MF 미구현
5. 조명 환경(HDRI)은 three.js `RoomEnvironment` 한 종을 노출도만 바꿔 사용 — 별도 HDRI 3종은 미구현

> 범위에서 **제외한 것**: 9:16 턴테이블 영상 녹화·저장, 프레임/뷰 PNG 캡처. v0.2 프로토타입에 있던 기능이며 v0.3에서 코드와 UI를 제거했습니다(PRD 4.2 · 7.5).

## 검증 결과 (`npm run verify`)

KS 12호 · 폭 4.0mm · 두께 1.8mm 기준:

| 프로파일 | 단면적 | 체적 | 18K | 925 | Pt950 |
|---|---|---|---|---|---|
| 돔 | 5.99mm² | 0.343cm³ | **5.40g** | 3.62g | 7.00g |
| 평면 | 7.17mm² | 0.416cm³ | 6.54g | 4.39g | 8.47g |
| 각진(베벨) | 6.36mm² | 0.366cm³ | 5.76g | 3.87g | 7.46g |

- 체적이 **파푸스 정리**와 1% 이내 일치 (메쉬 416.7mm³ vs 이론 416.8mm³)
- 세 프로파일 모두 **열린 엣지 0 / 비다양체 0**
- STL 크기 = `84 + 50 × 삼각형` 규칙 일치 (12,176 삼각형 → 608,884 bytes)
- 호수 환산: KS 1호 13.000mm / KS 12호 16.667mm / KS 12호 = US 6.2호

> ℹ️ PRD 초안(v0.1)의 중량 예시(KS12 돔 18K 4.2g)는 단면적을 4.7mm²로 잡은 과소 계산이었습니다. 실제로는 약 5.4g이며, PRD v0.2에서 정정했습니다(3.6절).

## 기술 메모 (설계 판단)

- **메쉬는 정점을 공유하는 인덱스 지오메트리**로 직접 생성합니다. three.js 기본 도형은 같은 위치의 정점을 중복 생성해 수밀 검사가 어긋나므로, 반지는 단면 프로파일을 회전시켜 만듭니다(시임까지 공유).
- **수밀 검사**는 좌표를 0.0001mm로 용접한 뒤 엣지 차수를 세어 판정합니다(열린 엣지 = 1회, 비다양체 = 3회 이상).
- **중량**은 화면에 보이는 메쉬의 체적을 그대로 적분합니다(스톤 제외, 주물 수축률 반영).
- **자유 조형**은 파라메트릭 메쉬를 복제·베이크해 정점 법선 방향으로 변위시킵니다. 조형 후에도 위상이 유지되므로 검증이 그대로 동작합니다.
- **렌더 온디맨드**: 카메라나 씬이 바뀔 때만 렌더해서 아이패드 발열·배터리 소모를 줄입니다.
- **보석 투과광(transmission)** 은 GPU 비용이 커서 기본은 근사 재질이고, 재질 패널에서 "고품질"로 켤 수 있습니다.
